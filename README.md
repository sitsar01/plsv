# Lab Maya PLSV

Lab maya interaktif Persamaan Linear Satu Variabel (PLSV) dalam bahasa Indonesia.

## Isi

- Lab Timbangan: timbangan dua piring yang miring mengikuti nilai coba, operasi sifat kesetaraan (tambah/kurang/kali/bagi kedua ruas), catatan langkah, urungkan/ulangi, dan jurnal percobaan
- Misi Kontekstual: harga buku tulis, tabungan Dina, dan tarif parkir, dengan pembahasan baku Soal/Diketahui/Ditanyakan/Penyelesaian/Jadi
- Sifat Kesetaraan
- Tantangan acak berskor dan Mode Bebas untuk persamaan ax + b = c
- Refleksi

## Menjalankan

Buka `index.html` di peramban, atau aktifkan GitHub Pages dari cabang `main` (folder root).
